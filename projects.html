Live demos for these are coming soon, tap "Read more" for the full brief on each.

AI & SaaS

AI Agent

A custom autonomous agent built to handle multi-step tasks, planning, tool use and follow-through, not just Q&A.

Designed as a general-purpose task agent that can be pointed at a workflow, research, data lookups, drafting, scheduling, and carry it through multiple steps with minimal hand-holding. Built on an agentic architecture with tool-calling, memory of the current task, and guardrails so it knows when to check in with a human.

AI & SaaS

Table Mind

An AI-powered reservation funnel, an AI calling agent and an integrated chatbot handle bookings end to end.

Table Mind is a reservation funnel built around two AI touchpoints: an AI calling agent that answers the phone and books tables by voice, and a website chatbot that does the same thing for visitors who'd rather type. Both write straight into a shared reservation system, so nothing gets double-booked or lost between channels.

AI & SaaS

MeetPK

An AI-assisted meeting and scheduling platform that removes the back-and-forth of finding a time.

MeetPK handles the coordination layer around meetings, reading availability, proposing times, sending reminders and summarizing outcomes, so organizing a call takes one message instead of five. Built as a SaaS product with an AI layer doing the scheduling reasoning in the background.

App Development

Intern Management System

An app for running an internship program end to end, onboarding, tasks and attendance in one place.

Built for HR/operations teams to manage interns without juggling spreadsheets: digital onboarding, task assignment with due dates, attendance and check-in tracking, and performance notes per intern. Admins get a dashboard view across the whole cohort; interns get a simple app to see what's assigned to them and log their progress.

App Development

Order Management System

A full order lifecycle app, from placement to fulfillment, with live status tracking.

Covers the full order flow for a growing business: order intake, inventory sync, status updates (placed → packed → shipped → delivered), and notifications at each step for both staff and customers. Built with a simple dashboard so the ops team can see every open order at a glance and catch delays before customers do.

App Development

Flash Swipe

A fast, swipe-based discovery app designed to get users from browsing to a decision in seconds.

A lightweight mobile app built around a swipe-to-decide interaction, quick cards, instant feedback, and a smooth gesture-driven interface tuned for one-handed use. Focused heavily on performance so every swipe feels instant, with the heavier logic (matching, ranking, sync) handled in the background.
